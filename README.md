# Lago delle Streghe - Web Page Project

Un progetto front-end che unisce narrazione, design pulito e HTML semantico

## Descrizione del progetto

Lago delle Streghe è una pagina web sviluppata come esercizio di stile e struttura, pensata per mostrare competenze in HTML semantico, CSS moderno, organizzazione dei contenuti e cura dell’esperienza utente.

Il progetto combina una narrazione evocativa ispirata all’Alpe Devero con una struttura tecnica pulita.

## obiettivi del progetto

- Applicare HTML semantico per creare una struttura chiara, leggibile e accessibile
- Utilizzare CSS moderno per ottenere uno stile pulito, coerente e responsive
- Organizzare i contenuti in sezioni logiche
- Produrre un codice ordinato, scalabile e facile da mantenere

## Tecniche utilizzate

1. HTML
   - struttura semantica completa (header, main, section, article, footer)
   - uso dei tag "figure" e "figcaption" per le immagini
   - pulizia e leggibilità del markup
2. CSS
   - layout responsive
   - palette coerente e leggibile
   - tipografia bilanciata per testi narrativi
   - classi oraganizzate in modo chiaro e mantenibile
   - attenzione alla leggibilità e all'esperienza del utente

## Design

- Struttura narrativa fluida
- Sezioni ben distinte e scorrevoli
- Immagini integrate in modo armonico
- Tono coerente con l'atmosfera del luogo



##### Progetto realizzato per consolidare le competenze front-end e approfondire l'uso di HTML semantico, CSS moderno e buone pratiche di struttura e design web.
